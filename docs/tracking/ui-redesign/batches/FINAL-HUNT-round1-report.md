## For the owner to know (test and CI)
- `cypress.config.js` has `retries { runMode: 1 }`: a Cypress spec that fails once and passes on retry is green in the gate, so a first-attempt red is hidden.
- CI runs only in UTC, so a local-versus-UTC bug cannot fail there (only `tests/unit/board-model.unit.mjs` sets `TZ`).
- `tests/pdf/85-ats-pdfminer-dates.test.mjs` always skips on CI (no python3/pdfminer installed); it is a known-limit todo.
- Timing-based tests with thin margins (`164-huge-paste-linear` wall-clock ratio; `tests/unit/ui-overlays.unit.mjs` and `180-ui-b3-dock-typing` real timers) and `settle` helpers that count ticks (a read after 10 scheduler turns) are the likeliest future flakes.
