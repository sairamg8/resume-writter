# Parity table: cover letter, ATS check, draft / improve tools, download, export, share (key `editor-letter-ats-export`)

Audited 2026-10-06 from SOURCE (src/) against the canvas version 1791271695-af84. Rule: `../PARITY-RULE.md` (UI only; every live function stays).
Canvas boards read for this area: EditorLetter, EditorAts, EditorDraft, EditorImprove, EditorDownload, EditorShare, Letter (the area's own), plus Public, ImportModal, Main, Empty, MobileEdit, MobilePreview for the places a function moved to or is missing from.
Not audited here (other areas): the Design drawer, Personal info, the section editors, the template gallery, the editor chrome (save status, layout toggle, alerts, avatar, cloud dot: see `editor-content.md` EDIT-001..EDIT-020). Entry points of this area in that chrome ARE rows below (cross-referenced as "= EDIT-0xx").
IDs use the prefix `ELAE-` (not `EDIT-`) because `editor-content.md` already owns EDIT-001...EDIT-0xx.

Status key: SAME (same place, same look; SAME also marks an invisible behaviour the canvas does not need to draw and the build must keep), RESTYLED (same function, new look or new wording), MOVED (same function, new place, still reachable and drawn there), CHANGED (the drawing alters what the function does, or hides part of it), MISSING (not drawn at all). A CHANGED / MISSING row's "Fix" is the UI-only change; for MISSING it also names the nearest drawn home.

Board short names: EdLetter = EditorLetter.dc.html (letter tab: 360 px sidebar + paper stage); EdDraft = EditorDraft.dc.html (draft modal over EdLetter); EdAts = EditorAts.dc.html (ATS right drawer beside the résumé page); EdImprove = EditorImprove.dc.html (Improve popover + Undo toast); EdDownload = EditorDownload.dc.html (Download menu open); EdShare = EditorShare.dc.html (Share modal); Letter = Letter.dc.html (the letter paper); Public = Public.dc.html; ImpModal = ImportModal.dc.html (Documents page).

Summary of what the canvas does to this area: (1) the Cover letter sidebar is cut from 5 blocks (Photo, Header Layout, Date/Recipient/Subject, Body, Closing) to 3 cards plus one collapsed "Letterhead" row, and the rich-text body becomes a plain box; (2) the ATS panel is redrawn as a short pass / improve list and loses the quick fixes, the parser view, the plain-text card, the six categories with points and the cap / no-keyword notices; (3) the Bullet Optimizer dialog (editable text, score, Auto-Fix, 60 verb chips, metric chips, 7 X-Y-Z templates, Copy) becomes a three-suggestion popover; (4) the Export menu becomes a split Download button whose menu drops Import and the letter items; (5) the Share modal becomes an on/off switch and drops the not-published, stale, loading, error and confirm-unpublish states.
