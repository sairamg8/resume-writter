# Parity table: phone layouts of the whole app (key `mobile`)

Audited 2026-10-06 from SOURCE (src/) against the canvas version 1791271695-af84. Rule: `../PARITY-RULE.md` (UI only; every live function stays).
Boards read: MobileHome (MH), MobileEdit (ME), MobilePreview (MP), MobileDesign (MD), MobileJobs (MJ), MobileProject (MPR). All six are 390 x 844 and static (links only, no state, no open menus). The desktop boards of the other areas (New, JobAdd, JobsInsights, Projects, Project*, Editor*, ShellMenus, States) were NOT re-read here; where a phone function lives on one of them the row says "see <area>.md" and the other parity files own the detail.
Status key: SAME (same place and look, or an invisible behaviour the build must keep), RESTYLED (same function, new look or wording), MOVED (same function, other place, still reachable and drawn there), CHANGED (the drawing alters what it does, or hides it so it is not reachable as drawn), MISSING (not drawn at all).
Accessibility is deferred (CLAUDE.md): aria, roles, focus traps and 44 px target sizes are not rows.

## 0. How the live app does "phone" (the map every row hangs on)

There is no separate phone app. Three mechanisms:
1. `useIsMobile(768)` (src/hooks/useMediaQuery.js:31-33, `!(min-width: 768px)`), used in exactly two places: the editor (src/pages/Editor.jsx:33) and, as `useMediaQuery`, the workspace shell's drawer reset (src/components/shell/WorkspaceLayout.jsx:63). Everything else is Tailwind breakpoints: `sm` 640, `md` 768, `lg` 1024, `xl` 1280.
2. Tailwind classes (`max-md:`, `md:hidden`, `sm:`, `max-sm:`) in the components cited below; the only `@media` in src/ is `prefers-reduced-motion` (src/index.css:145) and the custom variant `no-hover` = `(hover: none)` (src/index.css:9).
3. Touch media queries: `pointer-coarse:text-base` (16 px fields so iOS does not zoom) in about 40 components; `no-hover:opacity-100` (controls revealed on hover are always visible on touch, src/index.css:3-9, tests/unit/touch-reveal.unit.mjs); Tooltip is a no-op on touch (src/components/ui/Tooltip.jsx:12-41).

The canvas replaces three live chromes on a phone (Dashboard header, workspace top bar + drawer, editor panel header) with: a 56 px top bar (CV mark, CPWT-CV, avatar), a 72 px bottom tab bar (Documents / Applications / Projects) and, in the editor, a floating Edit / Preview / Design pill.
