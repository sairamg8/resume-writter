# Parity table: shell, Documents, New, Import, Public page, Legal, global states (key `shell-docs`)

Audited 2026-10-06 from SOURCE (src/) against the canvas version 1791271695-af84. Rule: `../PARITY-RULE.md` (UI only; every live function stays).
Canvas boards read: Main, New, ShellMenus, Empty, ImportModal, Public, Legal, States (the area's own), plus JobsInsights (where the Career history panel went). The Mobile*, Projects, Jobs and Editor boards were NOT read for this area: where a row says "mobile not read", see UNKNOWNS.
Not audited here (other areas): editor tabs, Share modal contents, the editor's template gallery, Jobs and Projects page bodies. Their entry points in this area's chrome ARE rows below. Accessibility is deferred: a11y-only behaviour (skip link, aria, focus traps) is not a row.

Status key: SAME (same place and look, or an invisible behaviour the build must keep), RESTYLED (same function, new look or wording), MOVED (same function, other place, still reachable and drawn there), CHANGED (the drawing alters what it does, or it is not reachable as drawn), MISSING (not drawn at all).
Board names: Main = Main.dc.html (Documents); New; Menus = ShellMenus; Empty; Import = ImportModal (modal over Main); Public; Legal; States.
The canvas top bar is one bar on every board: CV mark + "CPWT-CV", nav Documents / Applications / Projects, "Search everything" field with a `/` key cap, avatar circle (initials). Only the signed-in state is drawn, except the signed-out card in Menus.
